What We Do
MSP Field Operations
On-site and remote infrastructure work — network mapping, security auditing, PBX automation, and full observability.
🗺️

Network Recon

Full network discovery on arrival — nmap, arp-scan, masscan. Topology map, open ports, device fingerprinting. All logged to NVMe.

🔍

Security Audit

CVE scanning with Nuclei, web app testing with Nikto, SMB enumeration with enum4linux-ng. Wi-Fi auditing with Kismet and aircrack-ng.

👾

Wi-Fi Recon

zangagotchi hunts WPA2 handshakes autonomously. Syncs to zangpachi NVMe via rsync. Hashcat cracks offline — no cloud, no exposure.

🐬

Hardware Toolkit

Flipper Zero handles sub-GHz, NFC, IR, and BadUSB attacks. GPIO/UART wired to zangpachi for scripted automation on-site.

📞

PBX Automation

Vodia PBX REST API integration — CDR reporting, call analytics, webhook ingestion. Full dashboard at analytics.zangbot.online.

🤖

Local AI Inference

Qwen2.5:7b on Mac Studio (86-93 tok/s), phi3:mini on zangpachi for offline field use. No cloud dependency for routine analysis.
